# Código de conduta

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate as pessoas com respeito, aceite críticas construtivas, foque no que é melhor para a comunidade e não tolere assédio de nenhum tipo. Comportamentos inaceitáveis podem ser relatados ao mantenedor por uma [issue privada de segurança](https://github.com/mateuspestana/urutau/security/advisories/new) ou pelo contato do perfil no GitHub; toda denúncia será analisada com sigilo.
